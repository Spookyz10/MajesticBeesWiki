Amulets
Amulets are equippable items dropped by mobs in The Majestic Bees. Each amulet rolls a random set of buffs when it drops, the stat, value, and number of rolls depend on which mob dropped it.

Amulet List

When an amulet drops, it randomly selects a number of buffs from its pool based on its Rolls count. Each buff is chosen independently using its Roll Chance, and its value is a random number within the listed Range. Higher chance means that buff is more likely to be selected in each roll.
